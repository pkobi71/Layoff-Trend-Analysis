# Layoff-Trend-Analysis
An analysis of layoff trends from 2020-2023.
This project was split into two parts: A data cleaning phase and a data analysis phase.

## Cleaning
The dataset contains around 3,000 records, all of which were cleaned an standardized. Some of the issues resolved
involved inconsistent company names, duplicate entries, and missing values.

The data cleaning process is viewable in 'Data Cleaning.sql', which is located in the 'Project SQL Files' folder.

## Analysis
After the cleaning process was completed, layoffs trends were analyzed by various markers such as, company, industry, and country.
Using the data, a rolling sum was built of the total monthly layoffs from 2020-2023, in order to identify trends.

The data analysis process is viewable in 'Data Analysis.sql', which is also located in the 'Project SQL Files' folder.

## Source
The original dataset used is downloadable via the 'layoffs.csv' file.
